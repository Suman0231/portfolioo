3.1
SUBCHAPTER ONE

Computer Software

3.1.1 Introduction to Software

Hardware is the physical part of a computer. A program is a set of instructions given to a computer to perform a particular task.

Definition

Software is a collection of programs designed to perform specific tasks.

  • Controls hardware.
  • Manages hardware resources.
  • Integrates hardware components.
  • Tells hardware what to do and how to do it.
  • Helps users interact with computers.

3.1.2 Categories of Software

01

System Software

Manages and controls the computer system.

02

Application Software

Performs tasks for end users.

03

Web-Based Software

Accessed through a web browser.

04

Mobile Applications

Designed for smartphones and tablets.

3.1.3 System Software

System software manages and controls hardware and provides an environment for application programs.

A. Operating System

Main system software that manages resources and provides an interface between user and hardware.

B. Language Translators

Assembler

Assembly language → machine language.

Interpreter

Translates high-level language one statement at a time.

Compiler

Translates a high-level program in a single operation.

C. Device Drivers

Software that allows the operating system/computer to communicate with a hardware device such as a printer.

D. Utility Software

Helps manage, maintain and control computer resources. Examples: antivirus, backup and disk tools.

3.1.4 Application Software

Application software consists of programs developed to meet the specific requirements of end users.

3.1.5 Types of Application Software

Packaged Software — Ready-made/off-the-shelf software for general requirements and many users.

Tailored Software — Customized software developed for a particular user or organization.

Web-Based Software — Software accessed through a web browser, generally requiring Internet connectivity.

Mobile Applications — Applications designed for mobile devices such as smartphones and tablets.

3.1.6 File and Folder

File

Collection of related data and information stored under a unique name.

File Extension

Usually indicates file type or format, e.g. question.pdf.

Folder

Collection of files and subfolders used to organize information.

3.2
SUBCHAPTER TWO

Operating System

3.2.1 Introduction to Operating System

Definition

An Operating System (OS) is system software that manages computer resources and provides an interface between the user and hardware.

When a computer starts, the operating system is loaded into main memory/RAM. Examples include Windows, UNIX, Linux and macOS.

3.2.2 Functions of Operating System

01 · Memory Management

Tracks memory, allocates it to processes and releases it when no longer required.

02 · Process Management

Manages running processes and CPU allocation.

03 · File & Directory Management

Creates, renames, deletes and organizes files and directories.

04 · Device Management

Tracks peripherals and manages allocation and communication.

05 · User Interface

Provides a way for users to communicate with the computer.

06 · Security Management

Uses mechanisms such as passwords, user management and roles.

07 · Deadlock Prevention

Helps avoid processes remaining indefinitely blocked by resource conflicts.

08 · Resource Management

Manages CPU, memory, files and peripheral devices.

09 · Command Interpretation

Receives and interprets user commands.

3.2.3 Operating System Terminology

Multiprogramming

Multiple programs are kept in memory and CPU resources are shared among them.

Multitasking

Multiple tasks, processes, programs or threads are managed through rapid switching.

Multiprocessing

Uses more than one processor/CPU so multiple processes can execute concurrently.

Distributed System

A collection of autonomous computers/processors connected through communication links that work together.

3.2.4 Types of OS Based on User Interface

CUI

Character User Interface

Also known as CLI. Users type commands into a command shell.

  • Less user-friendly
  • Commands must be remembered
  • Character-based
  • Comparatively low resource requirement
  • Example: MS-DOS
GUI

Graphical User Interface

Uses icons, menus, windows, buttons and dialog boxes.

  • User-friendly
  • Easier to learn
  • Supports multitasking and multimedia
  • Generally needs more resources

3.2.6 Components of GUI

Window

Rectangular visual area for interacting with a program.

Menu

List of options used to perform actions.

Dialog Box

Small window used to display messages or receive input.

Button

Interactive element that performs an action.

Scroll Bar

Moves through content that does not fit on screen.

SUBCHAPTER THREE

Windows Operating System

3.3.1 Introduction to Windows

Windows is a GUI-based operating system developed by Microsoft Corporation. It provides a graphical environment for interacting with files, folders, applications and hardware.

3.3.2 Versions of Windows

Windows XPWindows VistaWindows 7Windows 8Windows 10

3.3.3 Features of Windows Operating System

GUI-based

Uses icons, menus, files and folders.

Built-in applications

Provides built-in/accessory programs.

Device drivers

Provides support for various devices.

Security

Provides security features.

Multitasking

Supports multiple tasks.

Multiprocessing

Supports multiple processors.

Peripheral support

Supports various peripheral devices.

3.3.4 Windows Desktop

The desktop is the main working background of a GUI-based operating system. It is the area where icons are organized and users begin interacting with Windows.
