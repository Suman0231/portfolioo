Welcome to MS-DOS

MS-DOS stands for Microsoft Disk Operating System. It is a command-line operating system where users interact with the computer by typing commands instead of clicking graphical menus.

In this tutorial, you will learn the most important DOS commands, what they do, their syntax, and practical examples.


Example DOS prompt: 

C:\>_

MS-DOS Commands

01. DIR

DIR is used to display files and folders inside the current directory.

Syntax:

C:\> DIR

Example:

C:\> DIR

Volume in drive C is DOS
Directory of C:\

MYFILES
NOTES.TXT
PHOTO.JPG
PROGRAMS

4 File(s)

You can also use options such as /P to display results page by page. 

C:\> DIR /P

02. CD

CD means Change Directory. It is used to move from one folder to another.

Syntax:

C:\> CD foldername

Example:

C:\> CD DOCUMENTS

C:\DOCUMENTS>

To move one level back: 

C:\DOCUMENTS> CD ..

C:\>

03. MD / MKDIR

MD means Make Directory. It creates a new folder. MKDIR can also be used.

Syntax:

C:\> MD foldername

Example:

C:\> MD PROJECT

C:\> DIR

PROJECT

A folder named PROJECT has now been created.

04. RD / RMDIR

RD means Remove Directory. It deletes an empty directory.

Syntax:

C:\> RD foldername

Example:

C:\> RD PROJECT

The PROJECT directory will be removed if it is empty.

05. COPY

The COPY command copies one or more files to another location.

Syntax:

C:\> COPY source destination

Example:

C:\> COPY NOTES.TXT BACKUP.TXT

        1 file(s) copied.

This creates a copy of NOTES.TXT called BACKUP.TXT.

06. DEL

DEL deletes a file from the current directory. ERASE is another name for this command.

Syntax:

C:\> DEL filename

Example:

C:\> DEL OLD.TXT

The OLD.TXT file will be deleted.

07. REN

REN means Rename. It changes the name of a file.

Syntax:

C:\> REN oldname newname

Example:

C:\> REN NOTES.TXT CLASS.TXT

NOTES.TXT will now be named CLASS.TXT.

08. TYPE

The TYPE command displays the contents of a text file directly in the command prompt.

Syntax:

C:\> TYPE filename.txt

Example:

C:\> TYPE NOTES.TXT

Welcome to my DOS tutorial.
This is my first text file.

09. CLS

CLS means Clear Screen. It removes the previous commands and output from the screen.

Example:

C:\> CLS

The command prompt will be cleared.

10. DATE

The DATE command displays or changes the system date.

Example:

C:\> DATE

Current date is Tue 09-01-2026
Enter new date:

Press Enter to keep the current date.

11. TIME

The TIME command displays or changes the system time. 

C:\> TIME

Current time is 07:30:00
Enter new time:

12. VER

VER displays the DOS version. 

C:\> VER

MS-DOS Version 6.22

13. VOL

VOL displays the volume label and serial number of a disk. 

C:\> VOL

Volume in drive C is DOS
Volume Serial Number is 1234-ABCD

14. HELP

HELP provides information about DOS commands.

Example:

C:\> HELP

You can also ask for help about a specific command. 

C:\> HELP DIR

15. EXIT

EXIT closes the DOS command interpreter or command prompt session. 

C:\> EXIT

📝 Final Practical Task

Now it is your turn. Complete the following exercise using a DOS command prompt.


  1. Open a DOS/command prompt.
  2. Display the current directory using DIR.
  3. Create a folder called DOSLAB using MD.
  4. Enter the DOSLAB folder using CD.
  5. Create another folder called BACKUP.
  6. Create a text file named NOTES.TXT.
  7. Display the contents of NOTES.TXT using TYPE.
  8. Make a copy of NOTES.TXT called MYNOTES.TXT.
  9. Rename MYNOTES.TXT to FINAL.TXT.
  10. Use DIR to verify your files.
  11. Delete FINAL.TXT using DEL.
  12. Go back to the parent directory using CD ...
⚠️ Safety Tip: Be careful when practicing commands such as DEL and RD. They can remove files or directories. For learning, use a dedicated practice folder rather than important personal files.
