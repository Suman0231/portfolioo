SQL Tutorial – Wildcards

1. What are SQL Wildcards?

  • SQL Wildcards are special characters used with the LIKE operator.
  • They help search for data using patterns.
  • % represents zero or more characters.
  • _ represents exactly one character.
  • Wildcards are commonly used in the WHERE clause.

3. Using % Wildcard

% matches zero or more characters.

Example 1: Names starting with S

SELECT *
FROM students
WHERE Name LIKE 'S%';
Output
Roll_Number Name Address Grade
2 Suresh Pokhara 12
3 Sumina Kathmandu 12
5 Sangita Palpa 11

Example 2: Names ending with "a"

SELECT *
FROM students
WHERE Name LIKE '%a';
Output
Roll_Number Name Address Grade
3 Sumina Kathmandu 12
5 Sangita Palpa 11

Example 3: Names containing "in"

SELECT *
FROM students
WHERE Name LIKE '%in%';
Output
Roll_Number Name Address Grade
1 Dinesh Kathmandu 11

Example 4: Address starting with K

SELECT *
FROM students
WHERE Address LIKE 'K%';
Output
Roll_Number Name Address Grade
1 Dinesh Kathmandu 11
3 Sumina Kathmandu 12

4. Using _ Wildcard

_ matches exactly one character.

Example 1: Names having exactly five letters

SELECT *
FROM students
WHERE Name LIKE '_____';
Output
Roll_Number Name Address Grade
4 Himal Dharan 11

Example 2: Names where second letter is 'u'

SELECT *
FROM students
WHERE Name LIKE '_u%';
Output
Roll_Number Name Address Grade
2 Suresh Pokhara 12
3 Sumina Kathmandu 12

5. Using [ ] Wildcard

[ ] matches any single character inside the brackets.

Example: Names starting with S or D

SELECT *
FROM students
WHERE Name LIKE '[SD]%';
Output
Roll_Number Name Address Grade
1 Dinesh Kathmandu 11
2 Suresh Pokhara 12
3 Sumina Kathmandu 12
5 Sangita Palpa 11

6. Using [^ ] Wildcard

[^ ] matches any single character that is NOT inside the brackets.

Example: Names not starting with S

SELECT *
FROM students
WHERE Name LIKE '[^S]%';
Output
Roll_Number Name Address Grade
1 Dinesh Kathmandu 11
4 Himal Dharan 11

7. Using - (Range) Wildcard

- specifies a range of characters inside square brackets.

Example: Names starting with letters A to H

SELECT *
FROM students
WHERE Name LIKE '[A-H]%';
Output
Roll_Number Name Address Grade
1 Dinesh Kathmandu 11
4 Himal Dharan 11

8. Escaping Wildcards

Sometimes you need to search for the actual wildcard characters such as % or _. In SQL Server, this can be done using an escape character.

Example: Search for values containing %

SELECT *
FROM Products
WHERE ProductName LIKE '%\%%' ESCAPE '\';

Explanation: The backslash (\) tells SQL that the next character (%) should be treated as a normal character instead of a wildcard.

9. Common Wildcard Patterns

Pattern Description
'S%' Starts with S
'%a' Ends with a
'%in%' Contains "in"
'_____' Exactly five characters
'_u%' Second letter is u
'[SD]%' Starts with S or D
'[^S]%' Does not start with S
'[A-H]%' Starts with letters A to H
'%\%%' ESCAPE '\' Contains the % character
