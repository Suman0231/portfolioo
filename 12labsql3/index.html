MySQL Tutorial – Aggregate Functions

1. What are Aggregate Functions?

  • Aggregate functions perform calculations on multiple rows.
  • They return a single value as the result.
  • Aggregate functions are commonly used with the SELECT statement.
  • They are often combined with the GROUP BY clause.
  • Common aggregate functions are:
    • COUNT()
    • SUM()
    • AVG()
    • MAX()
    • MIN()

3. COUNT() Function

COUNT() returns the total number of rows.

SELECT COUNT(*) AS Total_Students
FROM students;
Output
Total_Students
5

4. SUM() Function

SUM() returns the total of a numeric column.

SELECT SUM(Marks) AS Total_Marks
FROM students;
Output
Total_Marks
402

5. AVG() Function

AVG() returns the average value.

SELECT AVG(Marks) AS Average_Marks
FROM students;
Output
Average_Marks
80.4

6. MAX() Function

MAX() returns the highest value.

SELECT MAX(Marks) AS Highest_Marks
FROM students;
Output
Highest_Marks
91

7. MIN() Function

MIN() returns the smallest value.

SELECT MIN(Marks) AS Lowest_Marks
FROM students;
Output
Lowest_Marks
68

8. GROUP BY Clause

The GROUP BY clause groups rows having the same value.

SELECT Grade,
COUNT(*) AS Total_Students
FROM students
GROUP BY Grade;
Output
Grade Total_Students
11 3
12 2

9. SUM() with GROUP BY

SELECT Grade,
SUM(Marks) AS Total_Marks
FROM students
GROUP BY Grade;
Output
Grade Total_Marks
11 237
12 165

10. AVG() with GROUP BY

SELECT Grade,
AVG(Marks) AS Average_Marks
FROM students
GROUP BY Grade;
Output
Grade Average_Marks
11 79.0
12 82.5

11. HAVING Clause

HAVING filters grouped records.

SELECT Grade,
COUNT(*) AS Total_Students
FROM students
GROUP BY Grade
HAVING COUNT(*) > 2;
Output
Grade Total_Students
11 3

12. Common Aggregate Functions

Function Description
COUNT() Counts the number of rows
SUM() Returns the total value
AVG() Returns the average value
MAX() Returns the highest value
MIN() Returns the lowest value
