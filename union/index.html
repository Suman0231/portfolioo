Union in C

Understanding Union, Memory Sharing and Its Difference from Structure

1. What is a Union in C?

A union is a user-defined data type in C that allows different members to share the same memory location.

Unlike a structure, where every member gets its own memory, all members of a union use the same memory area.

Key idea: A union can store a value for only one member at a time. When a new member is assigned a value, the previously stored value may be overwritten.

2. Union Syntax

The general syntax for declaring a union is: 

union union_name {
    data_type member1;
    data_type member2;
    data_type member3;
};

Example:

union Data {
    int number;
    float decimal;
    char character;
};

A variable of this union type can then be declared as: 

union Data d;

3. Why Do We Need Union Despite Having Structure?

Structures and unions both allow us to group different data types under one name. However, they have different memory behavior.

A structure allocates separate memory for every member. A union shares one memory location among all members.

Example Situation

Suppose a program needs to store a value that can be an integer, floating-point number, or character, but only one type is needed at a particular time.

Using a structure would allocate memory for all three values. A union can use the same memory for all three. 

struct Data {
    int number;
    float decimal;
    char character;
};

union DataUnion {
    int number;
    float decimal;
    char character;
};
Union is useful when: different types of data are needed at different times and saving memory is important.

4. Simple Union Example

The following program demonstrates how a union is declared, initialized and accessed. 

#include <stdio.h>

union Data {
    int number;
    float decimal;
    char character;
};

int main() {

    union Data data;

    data.number = 100;

    printf("Number = %d\n", data.number);

    return 0;
}

Output:

Number = 100

5. Union Member Data Can Be Overwritten

All members of a union share the same memory. Therefore, assigning a value to one member changes the contents of that shared memory. 

#include <stdio.h>

union Data {
    int number;
    float decimal;
    char character;
};

int main() {

    union Data data;

    data.number = 100;

    printf("Number = %d\n", data.number);

    data.decimal = 25.5;

    printf("Decimal = %.2f\n", data.decimal);

    return 0;
}

Output:

Number = 100
Decimal = 25.50
Important: After assigning data.decimal, the union's shared storage now contains the representation of the floating-point value. The previously stored data.number value should no longer be treated as the active member.

Another Example

#include <stdio.h>

union Test {
    int x;
    char c;
};

int main() {

    union Test t;

    t.x = 65;
    printf("x = %d\n", t.x);

    t.c = 'A';
    printf("c = %c\n", t.c);

    return 0;
}
Remember: A union does not keep independent values for all its members. It provides one shared storage area.

6. Memory Allocation in Structure and Union

The most important difference between a structure and a union is how memory is allocated.

Structure Memory

In a structure, every member generally requires its own storage. Padding and alignment can also affect the final size. 

struct Example {
    int a;
    float b;
    char c;
};

Conceptually, the memory looks like:

int a Separate storage
float b Separate storage
char c Separate storage

Union Memory

In a union, all members start at the same memory address. The union must be large enough to hold its largest member, with alignment potentially affecting its size. 

union Example {
    int a;
    float b;
    char c;
};

Conceptually, the memory looks like:

Shared Memory int a
float b
char c
Key point: The size of a union is based on its largest member, subject to alignment requirements. The size of a structure is generally enough for all of its members plus any required padding.

7. sizeof Structure and Union

We can use the sizeof operator to find the amount of storage occupied by a structure or union. 

#include <stdio.h>

struct Example {
    int a;
    float b;
    char c;
};

union ExampleUnion {
    int a;
    float b;
    char c;
};

int main() {

    printf("Size of structure = %lu bytes\n",
           sizeof(struct Example));

    printf("Size of union = %lu bytes\n",
           sizeof(union ExampleUnion));

    return 0;
}

Typical result on many systems:

Size of structure = 12 bytes
Size of union = 4 bytes
Note: The exact size is implementation-dependent. Padding, alignment, and the sizes of C data types can cause different results on different systems and compilers.

8. Structure vs Union

The syntax of a structure and union is very similar, but their memory behavior is different.

Structure Syntax

struct Student {
    int roll;
    float marks;
    char grade;
};

Union Syntax

union Student {
    int roll;
    float marks;
    char grade;
};

In the structure, all three members can contain meaningful values at the same time. In the union, the members share the same storage, so only one member should generally be treated as the currently stored value.

9. Difference Between Structure and Union

Feature Structure Union
Keyword struct union
Memory allocation Separate storage for members Shared storage for all members
Member addresses Members generally have different addresses Members have the same starting address
Size The total Size of Structure is the sum of the size of all its members plus padding The total size of a union is the size of its largest member
Values All members can hold values simultaneously Writing values to a new member overwrites the previous member values.
Memory efficiency Uses more memory Saves memory
Use case When all related data is needed together When only one data is needed at a time

10. Quick Summary

  • A union is a user-defined data type in C.
  • All union members share the same memory location.
  • The size of a union is generally based on its largest member.
  • Assigning one member changes the shared storage.
  • A structure gives separate storage to its members.
  • A union can reduce memory usage when only one member is needed at a time.
  • Use a structure when all members need to store values simultaneously.
  • Use a union when different types can share the same storage.
